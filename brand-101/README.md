# YOLO Brand 101

Everything needed to set up and maintain YOLO branding for Twitter/X, Instagram, TikTok, and official docs.

## Folder Contents

- `brand-guidelines.md` - core brand rules (voice, colors, typography, usage)
- `asset-inventory.md` - what exists now vs what is still missing
- `platform-setup.md` - exact assets and dimensions per platform
- `checklists/launch-checklist.md` - launch + governance process
- `assets/logos/` - portable logo files for quick reuse
  - includes `yolo-logo-high-res.svg` (2048x1024 export-ready master)

## Quick Start

1. Read `brand-guidelines.md`
2. Open `asset-inventory.md` and confirm missing files
3. Follow `platform-setup.md` for channel-specific setup
4. Execute `checklists/launch-checklist.md` before publish
