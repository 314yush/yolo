# Brand Guidelines

## Brand Core

- **Brand:** YOLO
- **Primary tagline:** `Spin the wheel, open a trade.`
- **Support line:** `Zero-fee perpetuals on Base.`
- **Voice:** high-energy, playful, rebellious, transparent
- **Style:** neo-brutalist (hard edges, bold contrast, minimal softness)

## Color System

- `#CCFF00` - primary lime
- `#000000` - black base
- `#FF006E` - hot pink accent
- `#FFD60A` - yellow highlight
- `#FFFFFF` - white text

Asset accent colors in use:
- BTC `#FF9500`
- ETH `#627EEA`
- SOL `#14F195`
- XRP `#00AAE4`

## Typography

- Primary UI font: `Space Mono`
- Fallback used in logo SVGs: system sans/monospace
- Preferred style: uppercase and bold for hero labels and brand moments

## Logo Usage

Primary files:
- `assets/logos/yolo-logo.svg`
- `assets/logos/yolo-logo-monochrome.svg`

Rules:
- Prefer lime logo on dark backgrounds
- Use monochrome logo where platform requires tinting/monochrome
- Keep clear spacing around logo; avoid crowding with UI chrome
- Do not apply gradients, glows, or rounded-pill treatments that break brand style

## Canonical Technical References

- Metadata wiring: `frontend/src/app/layout.tsx`
- PWA manifest: `frontend/public/manifest.json`
- Windows tile config: `frontend/public/browserconfig.xml`
