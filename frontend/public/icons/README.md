# Icons Directory

This directory contains PWA (Progressive Web App) icons for YOLO.

## Required Files

All icons should be PNG format with transparent or black backgrounds:

- `icon-72x72.png` - 72x72px
- `icon-96x96.png` - 96x96px
- `icon-128x128.png` - 128x128px
- `icon-144x144.png` - 144x144px
- `icon-152x152.png` - 152x152px
- `icon-192x192.png` - 192x192px (Required minimum)
- `icon-384x384.png` - 384x384px
- `icon-512x512.png` - 512x512px (Required minimum)
- `roll-icon.png` - 96x96px (Shortcut icon)

## Design Guidelines

- **Maskable Icons**: Keep important content within 80% of the icon area (safe zone) for adaptive masking on Android
- **Background**: Black (#000000) or transparent
- **Accent Color**: Lime green (#CCFF00)
- **Style**: Neo-brutalist, bold, high contrast

See `/BRANDING_ASSETS_GUIDE.md` for detailed generation instructions.
